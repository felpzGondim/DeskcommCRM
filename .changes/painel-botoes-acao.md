titulo: Painel do agente consulta o Brisa Hub e pede análise com confirmação
---
O painel do agente ganhou ações para consultar boletos, contrato e ficha cadastral usando o servidor MCP externo cadastrado pela organização. O pedido de documentos só preenche a caixa de resposta, para revisão do atendente. Iniciar análise de inquilino exige confirmação e usa um identificador de pedido para evitar execução repetida. Se o Hub não anunciar a ferramenta ou não devolver os dados esperados, o painel informa o problema sem afetar a conversa.
